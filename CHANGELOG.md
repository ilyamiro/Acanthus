# Changelog

All notable changes to the Acanthus engine crates. The policy is in `acanthus docs versioning`.

## Unreleased

### Added

- ACN: a component with several child slots (`Tabs`: one panel per tab) takes child `i` in slot `i`; text-list props (`labels: ["A", "B"]`) can be set from markup. `Component::slots` (default: the root takes every child) is new.
- `acanthus grammar vim|textmate` prints an editor highlighter generated from the widget registry; `Functions::names` lists the registered functions.
- ACN ids declared inside a `Repeater` copy become `name_N`; inside the copy the plain name still resolves.
- `acanthus_markup::parse_all` recovers from a bad member (skips to the next line or `;`) and returns every syntax error in source order; `Hot` and `acanthus check` use it. `parse` still returns the first error.
- ACN `Repeater { count: N  Child {} }` expands into N copies of its children with `index` (0 to N-1) readable inside; counts are constant expressions checked at compile time.
- `acanthus docs [TOPIC]` prints the ACN spec or the versioning policy of the installed version, offline.
- `acanthus shot [--size WxH] [--scale S] [--script STEPS] [--time MS] FILE OUT.png` renders an ACN file offscreen through the headless harness.
- `acanthus_markup::bind_actions` registers the ACN function `action(command, target?, extra?)` on an `acanthus_app::Actions` registry (literal names checked at compile time); `Actions::knows(name)` is new.
- `acanthus-cli` crate with the `acanthus` binary: `check [--global NAME]... FILE...` compiles ACN files against the standard widget registry and prints caret diagnostics, `fmt [--check]` re-indents them, `new` writes a starter file.
- `acanthus_markup::Hot`: watches an ACN file, rebuilds it on change, keeps the last good tree when a save is broken and shows an error band with `file:line:col`.
- ACN `Behavior on prop { Tween { duration, easing } }` and `{ Spring { spring, damping, mass } }` now compile to `Node::animate`; `fmt_time` joins the built-in functions and `Functions::check_literal` lets a host check literal arguments (translation keys, action names) at compile time. The compiler no longer reports `Behavior` as unsupported.
- `acanthus_markup::build`: compiles a parsed ACN `Document` through a widget `Registry` into scene nodes. Every `name: expr` becomes an `Effect`-driven binding, `property` names and ids are readable (forward references work), `on_event` handlers run with the event argument as `value`, and names, kinds and calls are all checked first so a failure returns every located error and builds nothing. `Behavior` is reported as unsupported for now.
- `acanthus_markup::{parse, Document, Component, Member}`: the ACN parser (`acn N` version header, `id`, `property`, assignments, `on_` handlers, `Behavior on`, nested components, `;` or newline separators) with `file:line:col` errors and keyword hints, and `Document::check_names` which checks component and property names against a widget `Registry` with did-you-mean hints.
- `acanthus_markup::{Expr, Value, Scope, Functions}`: the ACN expression language (literals, paths, lists, arithmetic, comparison, short-circuit logic, ternary, indexing, whitelisted calls with the built-ins `min max clamp abs round floor ceil mix len`); `Expr::check` resolves every name and arity with did-you-mean hints before anything runs.
- `acanthus-markup` crate: the ACN lexer (`lex`, `Token`, `TokenKind`) and located diagnostics (`Span`, `Diagnostic` with `file:line:col`, a caret line and a did-you-mean hint); the syntax is specified in `docs/acn-spec.md`.
- `TextInput::scroll_y` and `content_height`: the vertical scroll offset and the wrapped height of a multi-line field; the `TextArea` card draws a thin scroll indicator from them when the text is taller than the area.
- `acanthus_widgets::menu`: `MenuSpec::open` and `MenuStyle::shadow`/`shadow_blur` give a menu the popup frame's open and close morph and a drop shadow (breaking for code building the spec by hand: the two fields are new).
- `acanthus_widgets::wave` with the `WaveSeek` and `FluidWave` components: a seek bar whose played part is a travelling sine (flattening when paused) that seeks on press and drag, and a filled swell of two sines.
- `acanthus_widgets::chart` with the `Chart` and `Sparkline` components: a list of numbers (new `Kind::NumberList` prop) plotted as a stroked line over an optional area fill and horizontal grid lines, on a canvas that repaints when the data changes.
- `acanthus_widgets::popup_frame` with the `PopupFrame` component: the card of a popup with a rounded fill, outline and drop shadow that scales in from its top edge while sliding down and fading (250 ms OutQuint) and out again (150 ms InQuint); the body and an optional wallpaper backdrop are its children.
- `acanthus_widgets::dialog` with the `Dialog` component: a modal card (title, message, buttons, Enter picks the primary one) over a scrim that fades in, blocks the pointer behind it and dismisses on a click outside the card or Escape, taking the focus while open.
- `acanthus_widgets::selector` with the `NumberSelector` and `TimeSelector` components: a value between minus and plus buttons changed by click, wheel and Up, Down, PageUp, PageDown, Home and End, clamped or wrapping, with decimals and zero padding; the time selector pairs hour and minute fields over minutes since midnight.
- `acanthus_widgets::tooltip` with the `Tooltip` component: a bubble centred under its target that fades in after a hover delay (700 ms by default) and hides at once when the pointer leaves.  The target's window `origin` and the `window` size keep the bubble inside the window and flip it above the target at the bottom edge.
- `acanthus_widgets::tabs` with the `Tabs` component: a tab row with an underline that eases to the selected label (click, Left, Right, Space, Enter) over one panel per tab, of which only the selected one shows.
- `acanthus_widgets::choice` with the `Checkbox` and `RadioGroup` components: labelled indicators that ease their fill, tick or dot, toggled or picked by click, Space, Enter and (radio) arrow keys, dimmed and inert when disabled.
- `acanthus_widgets::progress` with the `ProgressBar` and `Spinner` components: a determinate bar whose fill eases to the value or an indeterminate sliding segment, and a rotating arc drawn on a canvas; both rest under reduced motion.
- `acanthus_widgets::text_area` and the `TextArea` component: a bordered card (border follows focus) around a wrapping, scrolling `TextEdit`, with placeholder, theme colours and spacing and radii tokens, text mirrored to the `text` prop.
- `TextInput::multiline`, `Scene::text_edit`, `TextInput::undo` and `redo`: QML `TextEdit` semantics on the text field (Enter breaks lines, text wraps at the field width, Up, Down, Home and End move by visual line with a remembered column, selection and caret span lines, pointer placement and drag across lines) and Ctrl+Z, Ctrl+Shift+Z and Ctrl+Y history where typed characters merge into one step.
- `acanthus_anim::Smoothed`: QML `SmoothedAnimation` (velocity or duration, quadratic ease in and out, retargets splice onto the current velocity).
- `ListView::current_index` and `ListView::set_highlight`: QML `currentIndex` and `highlight` with `highlightFollowsCurrentItem`; the highlight moves and resizes with `Smoothed` (`ListViewConfig::highlight_move_velocity`, `highlight_move_ms`, `highlight_resize_velocity`, `highlight_resize_ms`, Qt defaults 400 px/s), and the view scrolls to keep it in sight until the user drags or flicks.
- Styled text as QML `Text.StyledText`: `<a href>` links (underlined, `Node::link_color`, `Node::on_link` for QML `linkActivated`, `Scene::link_at`), `<h1>` to `<h6>` headings, `<ul>`/`<ol>`/`<li>` lists with Qt's markers and indent, `<p>` and `<u>`, and whitespace collapsed as Qt does; `<em>` is no longer italic (Qt does not know it).
- Right-to-left text: a text node whose first strong character is right-to-left aligns right unless `Node::h_align` was called (QML implicit alignment, `TextStyle::h_align_explicit`); an explicit `HAlign::Left` now keeps wrapped right-to-left lines on the left, as in Qt.
- `Capitalization::SmallCaps`: QML `Font.SmallCaps`; lower-case letters are drawn as capitals at 70 % of the font size, as Qt does.
- `Gpu::is_lost`: device loss is reported instead of panicking; `acanthus-wayland` reopens the device and rebuilds every surface, and recreates a single lost surface, without restarting the application.
- `HAlign::Justify`: QML `Text.AlignJustify` for wrapped text; every line but the last of a paragraph reaches both edges.
- `acanthus_scene::FrameStats` and `Scene::stats`: layout and display-list time, primitive count and frame rate of the rebuilt frames, published at most twice a second; `acanthus_widgets::profiler::overlay` shows them.
- `acanthus_scene::Capitalization` and `Node::capitalization`: QML `font.capitalization` (upper, lower, capitalize) for text nodes.
- `Tokens::scale`, `PropSpec::scaled` and `Registry::with_scales`: component props (button and dropdown radius, search field padding and gap) follow the spacing and radius scales when not given.
- `acanthus_app::Keybindings`: key chords mapped onto `Actions` (verb, target, argument); registered with the compositor or the portal, and reachable over IPC through `serve`.
- `acanthus_scene::{DropArea, DragSource, DragData, DragOffer, DropEvent, DropAction, DropActions}`, `Node::drop_area`, `Node::drag_source` and `Scene::{drag_enter, drag_motion, drag_leave, drag_drop, drag_cancel, drag_active}`: drag and drop inside the scene and from other applications; `acanthus_wayland::{AppHandle::start_drag, DragOutcome}` and the `wl_data_device` drop target.
- `acanthus_wayland::{Capture, CaptureConfig, CaptureState, CaptureError}`, `App::capture` and `App::can_capture`: output capture over `ext-image-copy-capture-v1` or `wlr-screencopy-unstable-v1` with shared memory, one-shot or live up to a frame rate ceiling; `acanthus_widgets::screencopy::screencopy_view` shows the frames; `acanthus_image::MemorySlot` keeps one frame of a live source in memory.
- `acanthus_services::platform::shortcuts` (`Shortcuts`, `Shortcut`, `Chord`, `Launcher`, `Strategy`, `snippet`): global shortcuts bound at runtime in Hyprland or Sway, through the XDG GlobalShortcuts portal, or as a configuration snippet for Niri, Mango and others; feature `shortcuts`.
- `acanthus_wayland::{SystemClipboard, Selection}` and `App::clipboard`: the desktop clipboard through `ext-data-control-v1` or `zwlr_data_control_v1`; `acanthus_scene::{ClipboardBackend, Clipboard::set_backend, Scene::set_clipboard_backend}` route text widgets through it.
- `acanthus_wayland::{LockConfig, LockPhase}`, `App::lock` and `AppHandle::unlock`: `ext-session-lock-v1` with a lock surface per output and a signal of the lock phase.
- `acanthus_wayland::{WindowConfig, WindowState, WindowCommand, Decorations, ResizeEdge}` and `App::window`: xdg_toplevel windows with title, app id, size limits, close requests and interactive move and resize.
- Engine crates `acanthus-core`, `acanthus-anim`, `acanthus-color`, `acanthus-image`, `acanthus-scene`, `acanthus-render`, `acanthus-wayland`, `acanthus-io`, `acanthus-runtime`, `acanthus-services`, `acanthus-widgets` and `acanthus-app`, version `0.1.0`, not released yet.
- `Node::animate(Prop, Motion)`: QML `Behavior on <property>` for position, size, opacity, scale, rotation, colour, radius and border.
- `Tokens` (motion, spacing, radii) on `Theme`, `SettingKeys::reduced_motion` and reduced motion in `acanthus-anim` (`set_reduced_motion`, `reduced_motion`, `FAST`/`BASE`/`SLOW`).
- `cargo xtask api [--check]` and the per-crate public API lists in `docs/api/`, checked by `scripts/check.sh`.
- `PropSpec::themed`, `Registry::with_colors` and `Theme::role`: colour props follow theme roles when not given.
- `PortalSettings` (feature `portal-settings`) and `Theme::reduced_motion_system`: the desktop's animation preference.
- `acanthus_app::testing`: `Headless` (offscreen shots, scripted pointer and key replay on a virtual 60 Hz clock, stall injection, JSON frame log), `Script`, `Image`, `Run`.
- `acanthus_widgets::menu` (`menu`, `MenuItem`, `MenuEntry`, `Outcome`, keyboard helpers) and `acanthus_app::menu` (`context_popup`, `submenu_popup`).
- Examples `hello-bar`, `hello-popup` and `hello-widget`.
